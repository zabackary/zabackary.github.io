> Quiet Dark Modern Theme for Zed

quiet-dark-modern is a dark implementation of Visual Studio Code's Quiet Light,
modernized. I quite like the Quiet Light theme in VSCode, but it's light, so I
found someone who forked it to be dark online. When the modern version of VSCode
themes were released around 2024, I found I liked the darker colors so forked
that theme to be darker.

Originally, this theme was created for VSCode based on my tastes, but as I've
shifted to Zed, the colors have followed me. [Original project here.](https://github.com/zabackary/quiet-dark-modern)
