Another SPA (single-page application) showcasing the different bookmarklets I've
made over the years. A [bookmarklet](https://en.wikipedia.org/wiki/Bookmarklet)
is a "bookmark stored in a web browser that contains JavaScript commands that
add new features to the browser" (Wikipedia), and this site has some:

- Run with Turbowarp

  Adds a Turbowarp iframe to the Scratch website so you can run .sb3 projects
  faster without leaving the site. Note that it uses Turbowarp's cloud data
  server instead of Scratch's.

- Desmos Custom Colors

  Add new colors not in the default palate to the Desmos graphing calculator.

- Scratch 3 Dev Tools

  Loads Griffpatch's Scratch 3 Dev tools into the Scratch Editor without having
  to download the extension.

- Preview

  Click on the bookmark, then click on any hyperlink on the current webpage to
  open a lite version of the link in a new window.
