Platformer Platform is a platform to build platformers. You can use 50 blocks
in different ways to create a landscape to play a platformer with. It was
originally called "Candy Battle" after an idea my classmates had in 6th grade.

It features a full account system, PWA (Progressive Web App), and a community.
It even has its own CSS design system with cool animations.

The editor looks a bit like [Scratch](https://scratch.mit.edu) with block
catigories and a workspace.

Note: the physics engine was intended to be built by my friend, but he backed
out so the current one is pretty buggy.

Most passwords are `________` (8 underscores) and the admin login is `pp_admin`.
