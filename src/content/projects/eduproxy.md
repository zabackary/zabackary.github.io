An advanced proxy website for unblocking websites blocked by the APS district. I
added many admin controls to make it more morally right to me, and so it could
be moderated.

Part of the reason I built this was because several websites -- like
ja.m.wikipedia.org and zh.m.wikipedia.org -- were blocked for racist reasons.

I built the first prototype in 6th Grade.
