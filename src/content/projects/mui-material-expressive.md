> The new design language with the components you already use.

Material Expressive for MUI provides a generator,
[`createM3Theme`](https://github.com/zabackary/mui-material-expressive/blob/HEAD/src/createM3Theme.ts), which generates a theme for use in an
MUI `ThemeProvider`. You can generate color schemes on the fly from source
images as well as colors.

## Demo

The demo is hosted with Storybook.
